# AuraMusic

基于华为音乐 HarmonyOS NEXT **沉浸光感**设计语言的跨端聚合音乐播放器（Flutter：Windows / Android / HarmonyOS NEXT）。

## 核心特性
- **沉浸光感 + 大 R 角连续圆角**：动态呼吸雾团背景（支持关闭退回纯黑/纯白）、`SquircleBorder` 超椭圆连续圆角、液态玻璃（Liquid Glass）底部 Dock 栏（滚动果冻惯性回弹）。
- **双端响应式交互**：
  - 移动端：顶部 `首页 / 搜索 / 设置` 滑动导航（无底部 TabBar）、首页上半部分热播 Top 10 / 100 + 播放历史、下半部分自建/导入/本地智能扫描歌单。
  - 沉浸播放页：封面页（呼吸光环粒子 + 锥形进度光头粒子 + 右下角抽屉菜单）↔ 歌词页左右滑动切换；支持桌面歌词悬浮窗。
  - 队列管理：长按拖动排序、播放模式切换（列表循环 / 单曲循环 / 列表播放）、最近三次替换过的播放列表快捷切换。
- **社区 JS 音源插件与 OAuth 托管**：本地沙箱插件接口与 OAuth 授权管理，不内置任何受版权保护的私有音源。
